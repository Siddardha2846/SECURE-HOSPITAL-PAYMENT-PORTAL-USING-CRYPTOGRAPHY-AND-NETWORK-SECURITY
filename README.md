# SECURE-HOSPITAL-PAYMENT-PORTAL-USING-CRYPTOGRAPHY-AND-NETWORK-SECURITY
Secure Hospital Payment Portal using Flask, SQLite, SHA-256, RSA Digital Signatures, and AES-GCM Hybrid Encryption to demonstrate Cryptography and Network Security concepts in secure healthcare transactions.

🏥 Secure Hospital Payment Portal

A secure full-stack hospital payment web application developed using Python Flask, SQLite, and modern Cryptography & Network Security concepts.

The system demonstrates:

Secure Login & OTP Authentication
SHA-256 Message Digest
RSA Digital Signatures
AES-GCM Hybrid Encryption
Secure Transaction Processing
Profile & Payment Management
🔐 Security Logic
Transaction Amount	Security Technique
₹1 – ₹2000	SHA-256 Message Digest
₹2001 – ₹5000	RSA Digital Signature
Above ₹5000	Digital Signature + AES-GCM Encryption
